# Insight2Dynasty — Roadmap

## Completed Features

| Feature | Notes |
|---|---|
| Standings + Home | Current season standings, playoff bracket, recent transactions |
| Head-to-Head History | Owner vs owner comparison |
| Owner Records | Historical records, season breakdowns |
| Draft Results | Year-by-year boards, draft grades, pick ownership |
| League History | Champions, division winners, consolation bracket |
| Matchup Recaps | AI-generated recaps + predictions (Claude Haiku) |
| Newsletter Generator | Weekly newsletter from recap data |
| Power Rankings | History + trend tracking with weekly snapshots |
| Roster Analysis | Dashboard with team classification (Win Now / Rebuilding) |
| Taxi Squads | Per-team taxi squad view |
| Trade Grades | Algorithm-based trade evaluation with history |
| Trade Calculator | KTC-based roster-aware trade tool with pick tiers + PPG delta |
| Player Profile Modal | Scoring history, draft info, ownership history |
| Transactions | Trade/waiver history with metadata |
| Playoffs | Bracket visualization |
| Team Records | All-time franchise records: scoring, season totals, margins, streaks (reg + playoff), unluckiest seasons |
